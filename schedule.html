Schedule

The fourteen weeks

Course›Schedule

Two lectures a week, marked a and b, and one exercise due before the following week. Four blocks: the first teaches the engineering vocabulary the rest of the course relies on, the second teaches LLMs and agents, the third walks the lifecycle phase by phase with agents as participants, and the fourth asks what the engineer is accountable for.

Block I · Software engineering fundamentals

Weeks 1 to 3. The project is specified, designed and tested here by conventional means, so that there is something to compare against later.

Week Lecture a Lecture b Exercise
1 Introduction. Why software engineering has phases; the course, the project and the rules; the state of AI in development, and what the evidence says Processes and lifecycle models. Artifacts and gates, iteration, agile, DevOps, and where evidence is produced Toolchain, project choice, first user stories
2 Requirements engineering. User discovery, user stories, acceptance criteria, traceability Architecture and design. Design decisions, patterns, rationale, architecture decision records Specify one feature of your project with acceptance criteria
3 Testing and quality. Test levels, specification-based and structure-based testing, coverage and what it does not show, verification and validation Code review, maintenance, CI/CD. Why someone else looks, change in a living system, the pipeline as a gate Test one feature from its criteria, and review a peer's

Block II · LLMs and agents

Weeks 4 to 6. From week 4 the same project is developed with agents, feature by feature.

Week Lecture a Lecture b Exercise
4 How LLMs work, for engineers. Next-token prediction, tokens, context windows, training stages, strengths and limits Prompting and context engineering; the AI-assisted IDE. Modes, rules, memory files, indexing, and what changes in practice One story, three models
5 From LLMs to autonomous agents. The agent loop, tools and tool calling, memory, skills, MCP Engineering Agentic Workflows: Patterns, Processes, and Quality. Workflow or autonomous agent, five common patterns and how to choose, evaluator and optimizer in depth, where agents sit in the lifecycle, a first look at testing with AI Choose and apply an agentic workflow pattern
6 Multi-Agent Systems for Software Engineering. Roles, topologies and coordination: who decides, who checks, who stops Reliability, safety, and evaluation of agentic systems. Criteria, variance, LLM-as-judge, and what an evaluation misses Build one project feature with your pattern and specialized agents

Block III · AI across the software engineering lifecycle

Weeks 7 to 12. Each phase was already met in Block I; the second visit assumes the first.

Week Lecture a Lecture b Exercise
7 AI-assisted requirements engineering. Elicitation with and about AI, user research, from conversation to specification Specification-driven development. From requirements to executable specifications; the development spec as the contract with an agent Elicitation, twice, and one ADR for the chosen design
8 AI-assisted design and implementation. Design rationale and ADRs, prototyping and UI generation, code generation at scale Agent frameworks and tooling. Orchestration frameworks, vendor agent SDKs, MCP servers, skills and hooks, tracing and observability; when a framework is worth it and when a plain loop is enough Port your week 6 workflow to a framework and compare
9 Reviewing code nobody wrote by hand. Review for AI-written code, review by agents, and what a reviewer must still read Security of AI-generated code. What static analysis catches and what it does not; fabricated dependencies Security triage of your own code
10 AI-driven testing and quality assurance. Test design from requirements; the full version of the week 5 example Test generation and repair. TDD and CI with agents, judging generated tests, defects of omission Criteria, tests, and what is missing
11 AI-assisted maintenance and program repair. Change in a system nobody fully remembers writing AI DevOps. Deployment, monitoring, agents in operations and incident response Verify someone else's patch
12 Security of agents. Prompt injection, tool misuse, supply chain: the agent as attack surface Human and agent collaboration. Delegation, synchronous and asynchronous agents, team workflows, the engineer as agent manager Threat model your agent setup

Block IV · Judgement and synthesis

Weeks 13 and 14.

Week Lecture a Lecture b Exercise
13 Accountability, intellectual property, licensing. Approving software on a well-founded belief, and what that requires of you Course synthesis. The lifecycle revisited with agents in it The accountability statement, with the final submission
14 Project presentations Project presentations Presentation and reflection
