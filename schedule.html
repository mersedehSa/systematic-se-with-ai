Schedule

The fourteen weeks

Course›Schedule

One lecture topic a week, with one exercise due before the following week. Four blocks: foundations of software engineering, then quality and evolution, then developing software with AI, then professional practice. The AI material in Block III builds on methods already studied rather than standing apart from them.

Block I · Software Engineering Foundations

WeekLecture topicExercise topic
1 Introduction, software processes and lifecycle Software lifecycle and process selection
2 Requirements engineering Requirements elicitation, specification and quality
3 Software architecture and design Architecture modelling and design decisions
4 Implementation and code quality Implementation, refactoring and code quality

Block II · Software Quality and Evolution

WeekLecture topicExercise topic
5 Software testing Test design: equivalence partitioning, boundary values and unit testing
6 Verification, validation and quality assurance Verification, validation, reviews and coverage analysis
7 Software maintenance and evolution Maintenance tasks, bug fixing and impact analysis
8 Configuration management, CI/CD and DevOps Version control, CI/CD pipelines and automated quality checks

Block III · Systematically Developing Software with AI

Weeks 9 to 12 form one teaching unit: Systematically Developing Software with AI. Week 11 runs over two lectures, 11a and 11b.

WeekLecture topicExercise topic
9 Machine learning and AI applications in software engineering Identifying suitable ML and AI applications for software engineering tasks
10 Generative AI, LLM foundations, prompting and AI tools Prompt engineering and evaluating LLM-generated software artefacts
11a AI agents: tools, memory and context one exercise for week 11
11b Engineering agentic workflows Designing and applying an agentic workflow pattern
12 AI across the software engineering lifecycle Applying AI assistance to different software engineering lifecycle activities

Block IV · Professional Practice and Integration

WeekLecture topicExercise topic
13 Project management, ethics and accountability Evaluating professional, ethical and accountability issues in AI-assisted software development
14 Project presentations and reflection Final project demonstrations, presentations and reflection

Project milestones

The semester project runs from week 1. Each milestone is the output of that week's exercise, not extra work.

MilestoneWeekWhat is due
M0Week 2Project chosen, toolchain running, requirements documented
M1Week 4Architecture designed, first feature implemented and peer reviewed
M2Week 8Tested and quality assured, with CI/CD running on the repository
M3Week 12An increment developed with AI support, with the evidence that goes with it
FinalWeek 13The system, the engineering evidence, and the accountability statement
PresentationsWeek 14Group presentation and individual reflection
